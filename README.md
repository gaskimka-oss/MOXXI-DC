# 🎮 MOXXI — Discord Bot

Многофункциональный игровой и управляющий бот MOXXI для серверов Discord, написанный на `disnake` и синхронизированный с общей базой данных экосистемы MOXXI.

## 🌟 Возможности
- Префиксы: `!`, `m!`, `.` + слэш-команды
- Красочные Discord Embeds с кнопками
- 414+ команд: игры, экономика, дуэли, кланы, ферма, бизнесы
- Инвайт-ссылка с кнопкой прямо в чате: `!пригласить` / `!инвайт`
- Синхронизация профиля и монет с Telegram, VK и MAX

## 📦 Быстрый запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/gaskimka-oss/MOXXI-DC.git
cd MOXXI-DC
```
2. Скопируйте `.env.example` в `.env` и впишите токен бота:
```bash
cp .env.example .env
```
3. Запустите:
```bash
python main.py
```
или запустите `start.bat`.
